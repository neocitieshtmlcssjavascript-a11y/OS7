# 🖥️ OS7

> **OS7** is an atmospheric retro horror operating system simulator, developed from scratch in just **7 days**!

The project is inspired by the aesthetics of old PCs, analog horror, and classic games like *OS95*. The player will delve into the interface of a mysterious old system and discover what lies hidden within its files.

---

## 🚀 Project Features

* ⏱️ **Developed in 7 days** — the game was created under a tight timeframe (speedrun development).
* 💾 **Retro atmosphere** — a visual style inspired by operating system interfaces of the late 90s.
* 👁️ **Horror elements** — system exploration, hidden files, strange logs, and psychological tension. * 🌐 **Accessibility** — the project is optimized to run directly in the browser.
