# 🖥️ OS7

[GO PLAY GAME FREE GAME WINDOWS 7](https://github.com/neocitieshtmlcssjavascript-a11y/OS7/blob/main/game.md)
> **OS7** is an atmospheric retro horror operating system simulator, developed from scratch in just **7 days**!

The project is inspired by the aesthetics of old PCs, analog horror, and classic games like *OS95*. The player will immerse themselves in the interface of a mysterious old system and discover what lies hidden within its files.

---

## 🚀 Project Features

* ⏱️ **Developed in 7 days** — the game was created under a tight timeframe (speedrun development).
* 💾 **Retro atmosphere** — a visual style inspired by the interfaces of operating systems from the late 90s and early 2000s. Psychological tension.
* 🌐 **Accessibility** — the project is optimized to run directly in the browser.
